Un registro di [[Immagini Docker|immagini]] è una locazione centralizzata per immagazzinare le nostre immagini. Ad esempio il Docker Hub è un registro pubblico che tutti possono usare, esso è considerato il registro di default. Possiamo anche avere i nostri registri privati sul nostro sistema locale all'interno dell'organizzazione. Mentre lavoriamo con i registri, potremmo sentire i termini registro e repository come se fossero intercambiabili. Anche se sono correlati, non sono esattamente la stessa cosa. Un registro è una posizione centralizzata che archivia e gestisce le immagini dei contenitori, mentre un repository è una raccolta di immagini dei contenitori correlate all'interno di un registro.
